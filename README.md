 Super Mario Bros - Tribute Game 

¡Bienvenido/a a mi clon/tributo de **Super Mario Bros**! Este proyecto fue desarrollado desde cero con fines educativos para poner en práctica conceptos avanzados de desarrollo frontend, lógica de programación y manejo de estados en videojuegos web. Es una recreación interactiva que rinde homenaje al clásico juego de plataformas, diseñado con una estética retro pixel art.

---



##  Características del Proyecto

*   **Jugabilidad Clásica:** Controles fluidos para saltar, correr y mover a Mario a través del escenario.
*   **Sistema de Físicas y Colisiones:** Implementación de gravedad, saltos realistas e interacción precisa con bloques, plataformas y enemigos.
*   **Animaciones e Identidad Visual:** Uso de *spritesheets* animados para recrear la caminata, el salto y los estados de Mario.
*   **Diseño Responsivo/Adaptable:** El lienzo del juego se adapta correctamente para mantener la experiencia visual retro intacta.

---

## 🛠️ Tecnologías Utilizadas

El proyecto fue construido utilizando tecnologías web modernas y herramientas enfocadas en el desarrollo de videojuegos de alto rendimiento:

*   **HTML5 & CSS3:** Para la estructura general de la página y el contenedor del juego.
*   **JavaScript (ES6+):** Programación de toda la lógica, mecánicas de movimiento, control de eventos del teclado y manejo del estado del juego.
*   **Phaser Framework (v3):** Motor de videojuegos en 2D utilizado para gestionar el ciclo de vida del juego (*preload, create, update*), renderizado de sprites, mapas de bits y el motor de físicas.

---

## 🧠 Desafíos Técnicos y Aprendizajes

Desarrollar un juego de plataformas implica retos muy diferentes a los de una aplicación web tradicional. Durante este proyecto aprendí y dominé:

1.  **El Game Loop (Bucle de Juego):** Comprender a fondo cómo funciona la actualización constante de la pantalla (`update`) para calcular movimientos y estados en tiempo real de forma óptima.
2.  **Manejo de Vectores y Físicas:** Configuración de la gravedad, rebotes al golpear bloques por debajo y la inercia del personaje al correr.
3.  **Optimización de Recursos:** Carga eficiente de *sprites*, hojas de animación y assets de audio sin penalizar el rendimiento del navegador.
